
# Data Structures and Algorithms

## 1. Graph

Each brain region is a vertex. Each connection is an edge with a weight.

The implementation uses an adjacency list.

Typical graph storage complexity:
- Space: O(V + E)
- BFS: O(V + E)
- DFS: O(V + E)

V represents the number of vertices and E represents the number
of edges.

## 2. Queue

A queue follows FIFO: First In, First Out.

BFS uses a queue to explore nearby vertices before moving farther
through the network.

## 3. Stack

A stack follows LIFO: Last In, First Out.

DFS uses a stack to explore a branch before returning to alternatives.

## 4. Min Heap

A Min Heap provides access to the smallest priority value.

Dijkstra uses a priority queue to process the next lowest-cost
candidate vertex.

## 5. Linked List

A linked list stores elements in nodes connected through pointers
or references. It supports sequential traversal.

## 6. Binary Search Tree

A BST organizes values so that smaller values are stored on the left
and larger values on the right. Search and insertion can be efficient
when the tree is reasonably balanced.

## 7. Merge Sort

Merge Sort divides an array into smaller parts, sorts those parts,
and merges them.

Typical time complexity: O(n log n).

## 8. Binary Search

Binary Search repeatedly halves a sorted search range.

Typical time complexity: O(log n).

## 9. Dijkstra

Dijkstra finds a minimum-total-weight path in a graph with
non-negative edge weights.

It does not calculate a medical or biological pathway.
The result only describes the synthetic graph and weights supplied
to this educational project.
