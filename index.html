How it works

The following are graph algorithms implemented in the browser version.

BFS — Queue

Visits nearby vertices first using a FIFO queue. Useful for traversal and unweighted shortest paths.

DFS — Stack

Explores a branch deeply before backtracking. Can be implemented recursively or with a stack.

Dijkstra — Greedy shortest path

Finds a minimum-total-weight path when edge weights are non-negative.

Complexity note

This JavaScript Dijkstra implementation uses a simple vertex scan, approximately O(V² + E). A min-heap can improve performance on larger sparse graphs.
